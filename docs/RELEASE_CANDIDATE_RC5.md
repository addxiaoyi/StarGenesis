# RC5 模块化候选构建与验证

`4.0.0-rc.5` 在 RC4 稳定性实现上纳入通信确认歧义修复，以及 Helstera 模型查询/被动投影、CraftEngine 完整物品状态、Cookery 七类配方目录。基础插件和三个可选桥接各自输出 JAR；桥接保持 Paper 1.21.11 的既有提供方与功能限制。

插件源码基线为 `db15f3741637be688eaecf6f12071ee2c017cd09`。本批改造候选构建脚本与 CI，未修改 Java 生产源码；RC5 与该提交的 Java21 SNAPSHOT 逐字节比较全部 1,408 个 class，增加、删除和改变均为零。版本及构建资源随候选版本改变，不能据此把既有 SNAPSHOT 实服记录当成 RC5 实服记录。

## 回归与签名工具

构建器新增 5 项回归，连同原 3 项共 8 项通过；Python 相关子集共 29 项通过。覆盖所选模块独立复制、缺失测试不能借用基础模块报告、提供方源码锁失配、错误版本/混入提供方 class 拒绝，以及 POSIX checkout 无可执行位时通过 `sh mvnw` 构建。最初三项新用例在旧函数签名上报 TypeError，失败日志保留；没有声称旧构建器实际运行 RC5 后失败。

同一 RC5 基础插件在 Java21/25 各通过工作目录跨进程锁、结算锁、发行签名和设计包签名自检。另以一次性测试密钥为四个 JAR 加 SBOM 的副本生成 `4.0.0-rc.5` 联合清单，逐一篡改五个文件都被拒绝，恢复后验证通过，测试私钥已删除。原基础签名自检沿用测试清单版本 `1.0.0-rc.1`，实际源文件哈希明确指向本次 RC5；均不属于正式发行签署。

构建器用法和输入校验见 [隔离候选构建](RELEASE_CANDIDATE_BUILD.md)。CI 新增 Linux Java21 的实际三扩展候选构建，并归档独立 JAR、SBOM 与依赖证据；具体运行结果单独记录，不将本地成功视为 CI 成功。
