# 全阶段开发清单

目标：继续完成 StarGenesis P0–P11，按无人值守方式推进，以单元测试、持久化回归和可复现构建为主要反馈。基线为 `b86995d`，已完成 Arena 部分回合提交校验修复 `8b89f80`。本清单追踪剩余工程工作；阶段验收状态继续由 `PHASE_STATUS.md` 记录。

| 阶段 | 下一步工程工作 | 主要验证 |
|---|---|---|
| P0 | 持续维护模块、Schema/API 和线程边界 | 合同测试、边界扫描、Java 21/25 reactor verify |
| P1 | 检查停止/关闭/恢复与持久化失败时的生命周期 | 检查点、回放、重复停止和故障回归 |
| P2 | 共享编辑、公开查看、许可克隆和来源固定已实现；继续验证命令与长期生命周期 | 撤销授权、自授权拒绝、冲突保存、作者隔离、克隆来源、重启 |
| P3 | 核对编辑/预算/沙盒生命周期与边界输入 | 原语组合、预算耗尽、输入隔离、回放与持久化 |
| P4 | 完善通信与契约在容量、断线、重启、写盘失败下的恢复 | 去重、ack、超时、消息预算及故障矩阵 |
| P5 | 已加入1–1536步有界实验、跨寿命恢复与多 seed/参数研究；继续处理寿命后物种灭绝和平衡探索、实服长局验收 | 每步物质守恒、繁衍代数/出生上限、首次灭绝时点、恢复回放、长期三物种共存 |
| P6 | 已实现独立场次、成员退出、历史选择、活跃占用和管理员终局清理；继续核对新命令实服行为与四人故障比赛验收 | v1/v2 回放、竞价/订单/补偿写盘失败、共享 reset 权限、目录预算、重启与重组 |
| P7 | 已修复持久授权、自授权和编辑者扩权；继续核对依赖固定与审核恢复 | 禁止候选文档自授权、撤销权限、发布幂等与依赖边界 |
| P8 | 多场选择/恢复、退出/撤回、历史清理及新比赛的存档上界准入/目录预留已实现；继续核对新命令实服行为与长期多人性能 | 非法动作、重连、观战、v1/v2 回放、8 MiB终局上界、64 MiB活跃容量预留及真人公平性 |
| P9 | 补齐真实结算接入契约、恢复/人工复核管理和 provider 验收工具 | 幂等副作用、授权过期、并发恢复、补偿、未知结果；真实 adapter 必须依据实际 API |
| P10 | 完善 trust-root 与可验证的第三方桥接生命周期 | 当前信任重验、撤销、依赖/许可、服务退出与版本失配 |
| P11 | 汇总可自动执行的阶段验证、容量研究工具与候选发行流程 | 可重复构建、SBOM、签名篡改、完整测试和证据一致性 |

每个实现批次先检查实际代码与已有测试，补缺口后运行针对性回归及整仓验证，更新证据并保存本地提交。优先保持有效 v1 数据可读；必须改变持久格式或模拟语义时，增加明确版本和兼容/拒绝测试。

真人体验、留存/公平性研究、真实第三方故障验收、生产规模容量和发行方私钥签名需要对应环境或主体证据。单元测试中的替身与临时密钥只能证明测试契约，不能把这些阶段门改为通过；工程工作持续推进，不因这些验收暂缺而停下其他可做的任务。
